# Embaixadores Adsplay - Comunicados e Pontuação

Protótipo com dados fictícios, feito no padrão Adsplay Spec Kit (Vue 3, Vite, Tailwind e shadcn-vue). Não é um sistema pronto para produção.

## Como rodar
Precisa do Node 20.19 ou mais novo (ou 22.12+).

    npm install
    npm run dev

Abra o endereço que aparecer no terminal (normalmente http://localhost:5173).

## Entrar
Login fictício: escolha uma das 6 pessoas de exemplo. O perfil Aprovador pede uma senha de exemplo, que aparece na própria tela.

## Documentos
`specs/comunicados/`: spec, plano, tarefas e o briefing de integração (`integracao.md`).

Os dados voltam ao início ao recarregar a página.
